# Technology logo sources

The new SVG assets are stored locally so they do not rely on an external image CDN at runtime.

## Devicon

Files: `nextjs.svg`, `typescript.svg`, `tailwindcss.svg`, `supabase.svg`,
`postgresql.svg`, `wordpress.svg`, `figma.svg`, and `css3.svg`.

`vuejs.svg` uses `vuejs-original.svg` from the same pinned Devicon source.

Cloud assets: `googlecloud.svg` uses `googlecloud-original.svg` (the Google Cloud
brand for Google Cloud Run), and `aws.svg` uses
`amazonwebservices-original-wordmark.svg`, from the same pinned Devicon source.

Source: https://github.com/devicons/devicon/tree/7330accdbc47e2dc0c19789a48533c4a3c50fe58/icons

Each file uses the corresponding `{name}-original.svg` asset. The Devicon MIT
license is included in `DEVICON-LICENSE.txt`. Logos identify their respective
technologies; ownership and trademarks remain with their respective owners.
